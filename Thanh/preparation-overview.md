# OpenBio datathon preparation

This project collects information and preparation materials for the Harvard Undergraduate OpenBio Laboratory Datathon 2026.

**Preparation focus:** Track 1, bioinformatics: preeclampsia and RNA sequencing. The user selected this focus on November 10, 2026.

**Learning direction:** Start with clinical preeclampsia, normal placental biology, disease mechanisms, and maternal–fetal cell communication. Use cell biology and biochemistry to formulate questions and interpret evidence, then choose analyses that address those questions. The user is comfortable with cell biology/biochemistry and new to placental biology. This direction was established on November 10, 2026.

## Project notes

- [Event brief](docs/event-brief.md): dates, logistics, source links, and unresolved event details.
- [Track 1 preparation](docs/track-1-preparation.md): current challenge requirements, resources, and preparation checklist.
- [Biology-first learning roadmap](docs/biology-first-roadmap.md): clinical and mechanistic learning sequence, selected papers, and concrete learning outputs.
- [Biological meaning of the ten questions](docs/questions-biological-context.md): what each question asks, why it matters, and what evidence could answer it.

## How to maintain this project

Use organizer websites and the current organizer repository as primary sources. Date factual notes and distinguish confirmed requirements from proposed preparation work. Recheck event details before attendance and submission.

Registration, team membership, preferred analysis language, and prior RNA-seq experience have not yet been established. Preparation notes do not imply that software is installed or that an analysis has run.
